# Tarjeta NFC - Miguel Angel Tejada

Tarjeta de presentación NFC para desarrollador.

## Live
https://migueltejada86.github.io/tarjeta-nfc/

## Contenido
- `index.html` — página que se abre al tocar la tarjeta NFC
- `miguel-tejada.vcf` — contacto para guardar en el celular

## Cómo programar la tarjeta NFC
1. Comprá una tarjeta NFC en blanco (NTAG215 o similar).
2. En el celular instalá **NFC Tools** o **TagWriter by NXP**.
3. Escribí la URL: `https://migueltejada86.github.io/tarjeta-nfc/`
4. Listo. Al tocarla se abre la página con todos los contactos.
